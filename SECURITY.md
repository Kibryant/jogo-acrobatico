# Política de segurança

*English summary at the end.*

## Como relatar

Não abra uma issue pública para uma falha de segurança. Use o relato privado do GitHub: na aba **Security** do repositório, clique em **Report a vulnerability**. Só o mantenedor vê o relato.

Conte o que a falha permite, como reproduzir e qual commit você usou. Se tiver uma ideia de correção, ela ajuda.

## O que conta

- Falhas no código, nas ferramentas e no CI deste repositório: por exemplo, um jeito de rodar código na máquina de quem joga, de vazar um segredo ou de escrever no repositório sem permissão.
- Quando o jogo tiver partida online, uma trapaça que o servidor deveria barrar também conta.

Um bug comum vai numa issue normal.

## Versões

O projeto ainda não tem release; só a `main` recebe correções.

## O que esperar

O projeto é mantido por uma pessoa, no tempo livre, então a resposta pode demorar. Depois da correção, o GitHub permite publicar o relato como um aviso de segurança (security advisory), com crédito para quem relatou.

## English summary

Please do not open a public issue for a security problem. Report it privately through GitHub: open the **Security** tab and click **Report a vulnerability**; only the maintainer sees it. Say what the flaw allows, how to reproduce it and which commit you used. There are no releases yet, so only `main` gets fixes. This is a one-person hobby project, so a reply may take a while.
