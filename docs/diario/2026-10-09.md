### Conceitos novos

- **Ping em ticks:** a ida e volta em ms dividida por 16,7. São Paulo fica a 1,6 tick daqui; Miami, a quase 7.
- **CGNAT:** a operadora divide um IPv4 entre vários clientes. É como vários sites atrás do IP de um proxy, sem nenhuma rota apontando para o seu.
- **Gatilho:** cada serviço entra numa fase ou num número, nunca antes. Como só ligar o CDN quando o tráfego pede.
- **Preço por região:** a mesma máquina custa 1,5 vez em São Paulo. A API da Vultr tem o preço base e o `location_cost` de cada região.
- **Licença permissiva e copyleft:** a MIT deixa qualquer um fechar o código; a GPL obriga quem distribui uma versão mudada a abrir. É o React contra o Linux.
- **As referências dos PRs:** o GitHub guarda os commits de cada PR, só para leitura. Reescrever a main não apaga essas fotos do álbum.
- **Assinatura da build:** o certificado que diz ao Windows quem publicou o `.exe`. Como o HTTPS de um site: sem ele, o navegador avisa.
- **Imagem e contêiner:** o servidor empacotado com um Linux mínimo, que roda igual aqui e na nuvem. Um `package-lock.json` que trava até o sistema operacional.
