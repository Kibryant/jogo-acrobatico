### Conceitos novos

- **Replay por inputs:** guardar os comandos e refazer a partida, não gravar um vídeo. É event sourcing: o estado nasce da lista de eventos. O replay do LoL funciona assim.
- **Bit a bit:** a refeita só serve se der o mesmo número até o último bit. Por isso o float vai no arquivo como bytes, não como texto decimal arredondado.
- **Impressão das regras:** o sha256 dos scripts que movem o corpo. Um replay gravado com outras regras é recusado, a menos que se use `--force`.
